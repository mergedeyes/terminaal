# IBM i green screens (5250)

Terminaal has an IBM i (AS/400) 5250 terminal built in. You can reach a system
like [PUB400](https://pub400.com) in a tab next to your shells and SSH sessions,
with the same tab bar, split panes, colors, copy and search.

A 5250 screen isn't a VT terminal. The server sends whole screens with input
fields, you type into those fields locally, and nothing goes to the server until
you press <kbd>Enter</kbd> or a function key. Terminaal speaks this protocol
(TN5250, over telnet or telnet with TLS). It doesn't use the IBM i's VT100 mode.

## Adding an IBM i host

1. Open the sidebar (<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>B</kbd>), switch to
   **SSH** and click **+ Add host**.
2. At the top of the form, pick **IBM i (5250)** instead of **SSH**. The
   login, jump host, forwarding and advanced sections go away, and the port
   becomes 23.
3. Fill in:
   - **Host** – for example `pub400.com`
   - **Name** – what the sidebar and the tab show
   - **Encrypted (TLS)** – telnet over TLS. The port changes to 992. The
     server's certificate is checked against the ones your system trusts
   - **Code page (CCSID)** – see [Code pages](#code-pages)
   - **27 × 132 screens** – also offer the wide screen size. Programs that use
     it switch to it on their own
   - **Device name (optional)** – the name of the display device to ask for,
     up to 10 characters. Leave it empty and the server picks one (`QPADEV…`)
   - **Appearance** – a warning color or a theme of its own, as for SSH hosts
4. **Save**.

The list marks the host **5250**. Connect as you would to an SSH host: double-click
it, click **▶ Connect**, pick it in the [command palette](command-palette.md),
or start Terminaal with `terminaal --connect PUB400`.

Your user name and password go into the sign-on screen, like on any 5250
terminal. Terminaal never stores them.

In `hosts.toml` an IBM i host is a `[[host]]` with `protocol = "tn5250"`; see the
[configuration reference](configuration.md#hoststoml).

## The screen

- **Input fields** are underlined, as the server marks them. Password fields
  show nothing of what you type.
- The **status line** below the screen (when the pane has a row to spare) shows:
  - `X SYSTEM` while the server is working. The keyboard is locked until it
    answers
  - `X II` and an error number when a key wasn't allowed, for example typing
    outside a field (`0005`) or letters into a numeric field (`0009`). The next
    key clears it, or <kbd>Ctrl</kbd>+<kbd>R</kbd> (Reset)
  - `INS` in insert mode, `MW` when a message is waiting, and the cursor's
    row/column on the right
- The screen is 24 × 80 (27 × 132 with wide screens) and doesn't stretch. A pane
  smaller than that cuts the right or bottom edge off. Give it at least 80
  columns and 25 rows.
- When the connection ends, a red notice takes the status line's place:
  <kbd>Enter</kbd> connects again (to a new sign-on screen),
  <kbd>Ctrl</kbd>+<kbd>D</kbd> closes the tab.

## Keys

| Key | 5250 key |
| --- | --- |
| <kbd>Enter</kbd>, keypad <kbd>Enter</kbd> | Enter |
| <kbd>Ctrl</kbd>+<kbd>Enter</kbd>, <kbd>Shift</kbd>+<kbd>Enter</kbd>, <kbd>Ctrl</kbd>+<kbd>K</kbd> | Field Exit – clears the rest of the field and moves on |
| keypad <kbd>+</kbd> / <kbd>−</kbd> | Field+ / Field− in numeric fields, else the character |
| <kbd>Ctrl</kbd>+<kbd>X</kbd> | Field+ |
| <kbd>F1</kbd>–<kbd>F12</kbd> | F1–F12 |
| <kbd>Shift</kbd>+<kbd>F1</kbd>–<kbd>F12</kbd> | F13–F24 |
| <kbd>Page Up</kbd> / <kbd>Page Down</kbd>, mouse wheel | Roll Down / Roll Up |
| <kbd>Tab</kbd> / <kbd>Shift</kbd>+<kbd>Tab</kbd> | Next / previous field |
| Arrows | Move the cursor anywhere on the screen |
| <kbd>Home</kbd> | First input field; there already: Record Backspace |
| <kbd>End</kbd> | After the last character of the field |
| <kbd>Backspace</kbd> / <kbd>Delete</kbd> | Delete left of / under the cursor, within the field |
| <kbd>Insert</kbd> | Insert mode on/off |
| <kbd>Ctrl</kbd>+<kbd>End</kbd>, <kbd>Ctrl</kbd>+<kbd>E</kbd> | Erase to the end of the field |
| <kbd>Esc</kbd>, <kbd>Ctrl</kbd>+<kbd>A</kbd> | Attention |
| <kbd>Shift</kbd>+<kbd>Esc</kbd>, <kbd>Ctrl</kbd>+<kbd>C</kbd> | System Request |
| <kbd>Ctrl</kbd>+<kbd>R</kbd> | Reset |
| <kbd>Ctrl</kbd>+<kbd>P</kbd>, <kbd>Print Screen</kbd> | Print (on the server's printer) |
| <kbd>Ctrl</kbd>+<kbd>F1</kbd> | Help |

Terminaal's own shortcuts still come first:
<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>C</kbd>/<kbd>V</kbd> copy and paste, and
<kbd>Alt</kbd>+<kbd>1</kbd>–<kbd>9</kbd> switch tabs.

Keypad <kbd>+</kbd>/<kbd>−</kbd>, <kbd>Ctrl</kbd>/<kbd>Shift</kbd>+<kbd>Enter</kbd>,
<kbd>Shift</kbd>+<kbd>Esc</kbd> and <kbd>Print Screen</kbd> need the kitty keyboard protocol, which is on
unless you turned it off (**Settings → Terminal → Keyboard**). Without it, use
<kbd>Ctrl</kbd>+<kbd>K</kbd>, <kbd>Ctrl</kbd>+<kbd>X</kbd> and
<kbd>Ctrl</kbd>+<kbd>C</kbd>. Field− then has no key.

## Copying and pasting

Select with the mouse and copy as in any tab; the text is what the screen shows.
Pasted text is typed into the fields: a tab moves to the next field, a line
break to the first field of the next line. Pasting stops at the first character
a field won't take.

## Code pages

The server sends text in EBCDIC, in the code page of your display device.
Letters and digits are the same in all of them; umlauts, accents, `@`, `#`, `[`
and the like are not. Pick the one that matches the system's language:

| CCSID | Language | With € |
| --- | --- | --- |
| 37 | USA, Canada (default) | 1140 |
| 273 | Germany, Austria | 1141 |
| 277 | Denmark, Norway | 1142 |
| 278 | Sweden, Finland | 1143 |
| 280 | Italy | 1144 |
| 284 | Spain | 1145 |
| 285 | United Kingdom | 1146 |
| 297 | France | 1147 |
| 500 | International (Belgium, Switzerland) | 1148 |
| 871 | Iceland | 1149 |

Terminaal asks the server for a device with this code page (keyboard type, code
page and character set, as in RFC 4777). Double-byte code pages (Japanese,
Chinese, Korean) aren't supported.

## Limits

- Display sessions only: no printer sessions, no file transfer.
- No automatic sign-on, so no stored passwords.
- No enhanced 5250 GUI elements (pop-up windows as graphics, mouse-selectable
  menus). Terminaal reports a plain display station, and IBM i then draws
  windows with characters.
- Clicking doesn't move the cursor; use the arrows or <kbd>Tab</kbd>.
- Typing while `X SYSTEM` shows doesn't queue up. Wait for the screen.
- Plain telnet (port 23) sends everything unencrypted, your password too. Use
  TLS (port 992) where the server offers it – PUB400 does.
